## 📦 Módulo: Formulario de Contacto

**Fecha de inclusión:** 2025-09-19  
**Ubicación:** `/html/contacto.html`, `/js/formulario.js`  
**Descripción:**  
Se añadió un formulario con validación básica en JavaScript para capturar nombre, correo y mensaje del usuario.

**Características:**
- Validación de campos obligatorios
- Mensajes de error dinámicos
- Estilos adaptativos en CSS

## 🎨 Módulo: Estilos Responsivos

**Fecha de inclusión:** 2025-09-19  
**Ubicación:** `/css/responsive.css`  
**Descripción:**  
Se incorporaron media queries para mejorar la visualización en dispositivos móviles.

**Características:**
- Diseño fluido para pantallas menores a 768px
- Ajuste automático de fuentes y márgenes
- Compatibilidad con navegadores modernos
